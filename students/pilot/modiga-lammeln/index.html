Intro

Vad är en funktion?

En funktion är ett namngivet kodblock som du kan anropa när du vill. Istället för att skriva samma kod om och om igen — skriv den en gång i en funktion!

♻️
Återanvändbar
Skriv koden en gång, använd tusen gånger.
📦
Organiserad
Delar upp koden i logiska delar som är lätta att förstå.
🧪
Testbar
Enkel att testa och felsöka separat.
Syntax

Skapa en funktion

Använd nyckelordet def för att definiera en funktion, följt av ett namn och parenteser.

# Definiera en funktion
def säg_hej():
    print("Hej, världen!")

# Anropa funktionen
säg_hej()   # skriver ut: Hej, världen!
säg_hej()   # anropa hur många gånger som helst
säg_hej()
Kom ihåg: Koden inuti funktionen måste vara indragen med 4 mellanslag (eller ett tab). Python är känsligt för indragning!
Parametrar

Funktioner med parametrar

Parametrar är variabler du skickar in i en funktion så att den kan jobba med olika värden.

# En parameter: namn
def hälsa(namn):
    print("Hej,", namn)

hälsa("Hilda")   # → Hej, Hilda
hälsa("Erik")    # → Hej, Erik

# Två parametrar
def addera(a, b):
    print(a + b)

addera(3, 5)    # → 8
addera(10, 20)  # → 30
Return

Returnera ett värde

Med return kan en funktion skicka tillbaka ett värde som du kan spara eller använda vidare.

Utan return:

def dubbla(x):
    print(x * 2)

dubbla(4)  # skriver ut 8
# men inget värde sparas

Med return:

def dubbla(x):
    return x * 2

svar = dubbla(4)
print(svar)  # → 8
Tips: Använd return när du vill använda resultatet senare i koden!
Standardvärden

Parametrar med standardvärden

Du kan ge parametrar ett standardvärde (default). Då behöver man inte alltid skicka in det.

def hälsa(namn, hälsning="Hej"):
    print(hälsning, namn)

hälsa("Hilda")               # → Hej Hilda
hälsa("Erik", "God morgon")   # → God morgon Erik

# Räkna med standardvärde
def upphöjt(tal, exp=2):
    return tal ** exp

print(upphöjt(3))     # → 9  (3²)
print(upphöjt(2, 10)) # → 1024 (2¹⁰)
Sammanfattning

Det du lärt dig 🎉

  • 🔵def — nyckelordet för att skapa en funktion
  • 📦Parametrar — variabler du skickar in i funktionen
  • ↩️return — skickar tillbaka ett värde från funktionen
  • ⚙️Standardvärden — parametrar med ett förvalt värde
  • ♻️Funktioner gör koden återanvändbar och lättare att läsa
# En komplett funktion med allt!
def presentera(namn, ålder=0):
    return f"Jag heter {namn} och är {ålder} år gammal."

print(presentera("Hilda", 12))
# → Jag heter Hilda och är 12 år gammal.
